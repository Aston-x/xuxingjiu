# 配置说明

配置文件：`qqbot/config.json`（**不进版本库**，首次使用从 `config.example.json` 复制）。

`config.json` 里带 `_说明` / `_readme` 字段的，都是给人和 AI 读的注释 ——
JSON 不允许真注释，所以用这种合法字段代替。

改完有两种生效方式：

- **面板里改** → 即时写回文件并同步内存，不用重启；
- **手工改文件** → 重启进程，或调 `update_config()`（它会顺带重载模型端点）。

---

## 1. 必改项（第一次用）

| 键 | 说明 |
| --- | --- |
| `bot_qq` | 机器人 QQ 号。**必须与 NapCat 登录的那个号一致** |
| `access_token` | qqbot ↔ NapCat 的握手凭证。**自己编一串**，两边填一样的 |
| `ws_host` / `ws_port` | 反向 WS 监听地址与端口，默认 `127.0.0.1:6199` |
| `admin.user_ids` | 管理员 QQ 号列表。**为空 = 所有人都是管理员**（启动会警告） |
| `ban.protected_ids` | 豁免名单，任何情况下都不会被禁言。把你自己的号填进去 |

## 2. 对话与上下文

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `persona` | — | 核心人设：她是谁、怎么说话 |
| `world` | — | 她所处的环境设定 |
| `self_image` | — | 外貌描述，只在出图时用 |
| `identity_guard` / `identity_lines` | — | 被问「你是不是 AI」时的挡回话术与备用台词 |
| `style_boost` | — | 说话风格的强化提示 |
| `wake_prefix` | — | 唤醒前缀，命中必定回复 |
| `active_reply_probability` | 0.12 | 群里非定向消息的回复概率 |
| `max_context_turns` | 16 | 上下文保留轮数 |
| `max_reply_chars` | 240 | 单条回复长度上限（超了会拆条） |
| `split.max_bubbles` / `split.delay_seconds` | 3 / 0.9 | 长回复拆成几条、间隔多久 |
| `group_cooldown_seconds` | 3 | 群内回复后的冷却 |

> 想换成自己的角色：抄 `persona.example.json` 的骨架，把填好的字段覆盖进 `config.json`。

## 3. 模型（`providers` / 旧 `local` `cloud`）

**新写法**见 [providers.md](providers.md)。**旧写法**（仍支持）：

```jsonc
"local": { "enable": true, "base_url": "http://127.0.0.1:1234/v1", "model": "...",
           "api_key": "lm-studio", "timeout_seconds": 240, "concurrency": 1, "vision": true },
"cloud": { "enable": true, "base_url": "https://api.deepseek.com", "model": "...",
           "api_key": "", "api_key_env": "DEEPSEEK_API_KEY",
           "thinking": "disabled", "max_tokens": 1024, "timeout_seconds": 90, "vision": false }
```

两套同时存在时**以 `providers` 段为准**，启动日志会打印映射结果。

系统级开关：

| 键 | 说明 |
| --- | --- |
| `vision_enable` | 识图总闸。false 时谁都不看图 |
| `vision.backend` | `auto` / `cloud` / `local` / `off` |
| `vision.max_side_cloud` / `max_side_local` | 发给云端 / 本地的图片最长边（两档不同，别混） |
| `vision.max_frames` / `max_total_images` / `max_bytes` | 动图抽帧数、单次总图数、总字节上限 |
| `vision_relay` | 老键：`true` = 图在本地看、话在云端说 |

## 4. 她的生活（`life` / `self_activity`）

| 键 | 说明 |
| --- | --- |
| `life.enable` | 总闸 |
| `life.schedule` | 作息表：时间段 → 在做什么、忙不忙 |
| `life.mood_events` | 每天随机挑一条的心情事件 |
| `life.delay_min_seconds` / `delay_max_seconds` | 她"看到消息"的延迟范围 |
| `life.busy_at_silent_chance` | 忙的时候看手机的概率 |
| `self_activity.acts` | 她自己在做的事（含权重、心情倾向、被打断时的回应概率） |
| `self_activity.places` | 她在哪 |
| `self_activity.min_gap_minutes` / `max_gap_minutes` | 两件事之间隔多久 |
| `activity.report_minutes` | 活动报告间隔（默认 90 分钟） |
| `activity.report_to_admin` | 报告发到管理员私聊 |

## 5. 记忆与好感（`memory` / `affinity` / `mood`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `memory.enable` | true | 总闸 |
| `memory.reset_hour` | 4 | 每天几点做日切 |
| `memory.reset_every_days` | 3 | 短期内容几天淡出 |
| `memory.ask_admin_before_remember` | true | 拿不准要不要记时问管理员 |
| `memory.max_people` | 12 | 最多记多少人 |
| `memory.extract_every_messages` | 60 | 每多少条消息提炼一次 |
| `affinity.tiers` | — | 好感度档位（百分制）与各档的说话方式 |
| `affinity.decay_per_day` | 1.5 | 长期不联系会掉好感 |
| `mood.*` | — | 心情的增减与回落到好感的系数 |

## 6. 权限与禁言（`admin` / `ban`）

`admin.restrict.*` 里每一项控制对应功能是否**仅管理员可用**：

```
qzone_post  qzone_draw  ban  clear  persona  qzone_like  qzone_read
search  chat_draw  bili_login  qzone_comment
```

`ban.*` 是安全阀：`default_minutes`（默认 10）、`max_minutes`（1440）、
`self_max_minutes`（她自己起意的上限，60）、`max_per_hour`（3）、
`max_per_day`（10）、`same_target_cooldown_seconds`（600）、`protect_admins`。

## 7. B 站（`bili`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `bili.enable` | true | 总闸 |
| `bili.auto_login` / `qr_path` / `qr_wait_seconds` | — | 扫码登录相关 |
| `bili.daily_action_cap` | 6 | **每日点赞+投币+收藏总数上限** |
| `bili.like_probability` / `coin_probability` / `fav_probability` | — | 各自的发生概率 |
| `bili.browse_probability` | 0.5 | 每次循环去浏览的概率 |
| `bili.login_check_minutes` | 60 | 多久检查一次登录态 |

登录态在 `qqbot/bili_state.json`（含 `SESSDATA`，**不要提交 / 分享**）。

## 8. 天气与空间（`weather` / `qzone`）

| 键 | 说明 |
| --- | --- |
| `weather.enable` / `city` / `timezone` | 天气联动，用 open-meteo（免费、无需 key） |
| `weather.change_temp_delta` | 降温多少度她才念叨 |
| `qzone.bridge_url` | 空间桥地址，默认 `http://127.0.0.1:5700` |
| `qzone.auto_interact_enable` | 要不要主动去好友空间互动 |
| `qzone.auto_interact_probability` | 主动互动的概率 |

## 9. 控制台（`console`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `console.enable` | true | 开关 |
| `console.port` | 6200 | 端口 |
| `console.token` | 空 | 固定令牌（空 = 每次生成随机值写进 `state/console-token`） |
| `console.log_sources` | — | 日志来源表，不配就按同级目录推导 |

## 10. 出图（`sd`）

指向 Stable Diffusion WebUI（默认 `http://127.0.0.1:7860`），含每日配额、
图片尺寸、负面提示词等。不出图就把 `sd.enable` 关掉。

---

## 改坏了怎么办

`update_config()` 每次写盘前都会把上一份配置滚动备份到
`qqbot/_backup/console-config-last.json`。配置写坏导致起不来时：

```bat
copy qqbot\_backup\console-config-last.json qqbot\config.json
```

还不行就重新从 `config.example.json` 复制一份，只改第 1 节那几个必改项。
