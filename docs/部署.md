一键安装：

| 系统 | 命令 |
| --- | --- |
| Windows | 双击 `install.bat`（或 `powershell -ExecutionPolicy Bypass -File install.ps1`），要带参数就走命令行 |
| Linux / macOS | `bash install.sh` |

它会**先探测本机环境**（系统 / 发行版 / 包管理器 / 权限 / Python / Node / git / 网络），
然后缺什么补什么：能自己装的自动装，动系统包管理器之前问一句，装不了的把命令摊给你。
常用参数（三个入口通用，Windows 上把 `--xxx` 写成 `-Xxx`）：

| 参数 | 作用 |
| --- | --- |
| `--detect` | **只报告本机环境，一个文件都不动** —— 出问题先跑这个最省事 |
| `--detect --json` | 同上，输出机器可读的 JSON（CI 会拿两平台互相比对） |
| `--check` | 只检查、不动任何文件（CI 用） |
| `--yes` | 无人值守：系统级依赖也不再询问 |
| `--no-system` | 绝不碰系统包管理器，缺什么只打印命令 |
| `--dry-run` | 把要做的事全打印出来，什么都不做 |
| `--mirror auto\|off\|tuna\|aliyun` | 下载源策略，默认 `auto`（官方源慢/不通就切清华） |
| `--with-browser` | 额外装 Playwright chromium（约 150 MB，刷空间 Cookie 才需要） |

装完不确定哪里不对，跑 `/path/to/qqbot/.venv/bin/python qqbot/tools/doctor.py`
（Windows：`qqbot\.venv\Scripts\python.exe qqbot\tools\doctor.py`）。
