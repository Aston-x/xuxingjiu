# 生图（imagegen）

「出一张图」这件事在 `qqbot/imagegen/` 里，设计和对话模型那层（`providers/`）同构：
**后端可插拔、能力可声明、可配回退链、成本可控**。

---

## 1. 一分钟决定怎么配

| 你的情况 | 怎么配 |
| --- | --- |
| 本机装了 SD WebUI / ComfyUI | 只改 `imagegen.endpoints`，`tier: "local"` |
| 想用云端（不想占显存） | 加一个云端端点，`api_key_env` 指向环境变量，**设 `max_per_day`** |
| 两个都想有，按情况切 | 两个端点都加，用 `chains.image` 排优先级 |
| 什么都不想装 | `sd.enable: false`（或 `imagegen.enable: false`），她就完全不画图 |

**老配置不用改**：只写顶层 `sd` 段时，会自动推导出一个本地端点（`provider: sd_webui`），
行为和以前完全一致。

---

## 2. 配置形态

```jsonc
"imagegen": {
  "enable": true,                 // 总闸（与 sd.enable 是「与」关系，任一关就不画）
  "probe_seconds": 300,           // 探针缓存 TTL
  "endpoints": [
    { "id": "local-sd", "provider": "sd_webui", "tier": "local",
      "base_url": "http://127.0.0.1:7860", "timeout": 300,
      "params": { "steps": 28, "cfg_scale": 6.5, "sampler_name": "DPM++ 2M Karras",
                  "enable_hr": true, "hr_scale": 1.35 } },

    { "id": "cloud-x", "provider": "openai_images", "tier": "cloud",
      "base_url": "https://api.openai.com/v1", "model": "gpt-image-1",
      "api_key_env": "OPENAI_API_KEY", "timeout": 120, "max_per_day": 5 }
  ],
  "chains": { "image": ["local-sd", "cloud-x"] },   // 顺序即优先级
  "cloud": { "max_per_day": 5, "allow_when": "always" }
}
```

`params` 里的键会**原样进请求体**（各后端的参数名不同，所以不做统一抽象）。

### 云端成本控制

| 键 | 作用 |
| --- | --- |
| `endpoints[].max_per_day` | 该端点当天最多出几张（0 = 不限） |
| `cloud.max_per_day` | 所有云端端点的默认上限 |
| `cloud.allow_when` | `always` / `low-spec`（只有 ≤1024×1024 且不开放大时才走云端）/ `never` |

计数器落在 `qqbot/state/imagegen_state.json`（**不进版本库**）。

## 3. 内置后端

| provider | 类型 | 状态 |
| --- | --- | --- |
| `sd_webui` | 本地 Stable Diffusion WebUI（A1111 / Forge / reForge） | ✅ 实测 |
| `comfyui` | 本地 ComfyUI（工作流注入） | ✅ 形状实测 |
| `sd_next` | 本地 SD.Next | ⚠️ 未实测（接口同 A1111） |
| `invokeai` | 本地 InvokeAI | ⚠️ 未实测，**只支持固定 graph 模板一条路径** |
| `openai_images` | OpenAI `gpt-image` / `dall-e` | ⚠️ 未实测 |
| `dashscope` | 通义万相（异步任务） | ⚠️ 未实测 |
| `cogview` | 智谱 CogView | ⚠️ 未实测 |
| `siliconflow_image` | 硅基流动 | ⚠️ 未实测 |
| `gemini_image` | Google Gemini / Imagen | ⚠️ 未实测 |

「未实测」的含义：**适配器按公开文档写，但作者没有可用环境跑通它**。
这些后端的 `probe()` 会自报 `unsupported`，`tools/doctor.py` 也会标出来。
**它们不会假装成功** —— 接口对不上时会明确失败并把服务端原话打进日志。

> ComfyUI 的工作流模板与 InvokeAI 的 graph 模板见
> [`qqbot/imagegen/workflows/README.md`](../qqbot/imagegen/workflows/README.md)。

## 4. 能力声明

每个端点可以声明自己支持什么，调用方据此决定「要不要把图换成文字」「尺寸要不要吸附」：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `free_size` | `true` | 尺寸能否自由指定。**云端基本都是 `false`** |
| `size_step` | `8` | 本地后端要求对齐的步长 |
| `presets` | `()` | `free_size=false` 时允许的档位，会**吸附到最近的一档** |
| `negative` | `true` | 是否支持负面提示词（CogView-4 / OpenAI 系不支持，传了会被拒） |
| `hires` | `true` | 是否支持放大/二次采样 |
| `returns` | `b64` | `b64` 还是 `url`（url 的会自动再下载一次） |
| `moderation` | `false` | 有内容审核（提示词可能被拒，别以为是程序 bug） |
| `max_bytes` | 32MB | 单图上限，**流式下载时用它防 OOM** |

在端点上写 `capabilities` 可以逐端点覆盖适配器默认值。

## 5. 验证

```bash
# 生图层离线单测（不联网、不开 SD）
.venv/bin/python test_imagegen.py

# 完整体检（含生图端点可达性；--deep 才会真去探）
.venv/bin/python tools/doctor.py --deep
```

控制台的「模型端点」面板（B21）会列出每个生图端点的状态：
是否可用、为什么不可用（`skip_reason`）、密钥来源、云端今日用量、退避剩余秒数。

## 6. 从旧版 `sd` 配置迁移

旧 `sd.*` 会自动映射：

| 旧键 | 新位置 |
| --- | --- |
| `sd.enable` | 端点 `enabled`（`imagegen.enable` 是额外的总闸） |
| `sd.base_url` / `sd.timeout_seconds` | 端点 `base_url` / `timeout` |
| `sd.steps` / `cfg_scale` / `sampler` / `hires.*` | 端点 `params` |
| `sd.character_tags` / `solo_prefix` / `duo_prefix` / `ban_*` / `size.*` | **留在 `sd` 段**（这些跟"许杏玖这个人"绑，不跟后端绑） |
| `sd.pre_reply_lines` | **留在 `sd` 段**（出图前的话术） |
| `sd.fail_lines` / `sd.fail_enable` | **留在 `sd` 段**（出图失败时的话术与开关） |
| `sd.max_per_day_*` | **留在 `sd` 段**（三档配额是产品规则，不是后端参数） |

启动时会打印一行迁移提示，照做即可；不做也能跑。

## 7. 常见坑

1. **云端尺寸只认固定档**。`832x1216` 直接发过去会 400 —— 适配器会先吸附到最近档
   （`fit_size`），但如果你自己覆盖了 `capabilities` 而没给 `presets`，就会漏掉这一步。
2. **ComfyUI 的 `node_errors`**。`POST /prompt` 即使工作流有问题也返 200，
   只是带一个 `node_errors`；不看它就会一直轮询到超时。适配器**会立刻失败并报出原因**。
3. **负缓存（退避）**。后端刚挂过会被记 60 秒（本地）/ 180 秒（云端），
   期间直接判定为不可用、不发请求。刚重启后端却被挡住时，点控制台的**「重载配置」**清缓存。
4. **额度只在失败时退一次**。老代码有两处退还，某些路径会多退一张
   （`sd_state.json` 凭空少一张，很难复现）；现在收敛成单一出口，并有回归用例钉住。
