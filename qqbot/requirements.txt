# QQ 机器人直接依赖（最小版本下限，不是锁定）
#
# 为什么用 >= 而不是 ==：
#   项目要能在多个 Python 版本上跑（实测 3.11 / 3.13，CI 另测 3.14）。
#   如果钉死「在某个老 Python 上解析出的版本」，pillow / websockets 这类带 C 扩展
#   的包在更新的 Python（如 3.14）上往往没有对应的预编译 wheel，pip 只能回退源码
#   编译 —— 在没装 C 编译器的机器上直接失败，表现就是「python3.14 环境就用不了」。
#   改成 >= 下限后，pip 会为每个 Python 选「有 wheel 且兼容」的较新版本。
#
# 想要可复现构建（锁死版本）时：
#   .venv\Scripts\python.exe -m pip freeze > requirements.lock.txt
#   之后用 `pip install -r requirements.lock.txt` 即可完全复现本机环境。
#
# 升级依赖后务必跑 qqbot 三套测试确认没破坏行为：
#   test_regression.py / test_providers.py / test_imagegen.py
